# Lab 2 - VGA Graphics (Circles and Triangles)

## Overview
SystemVerilog implementation of VGA graphics on the DE1-SoC FPGA board.

## Tasks
- **Task 1**: Understanding the VGA adapter core
- **Task 2**: Fill screen with colour stripes
- **Task 3**: Bresenham circle algorithm
- **Task 4**: Reuleaux triangle

## Hardware
- DE1-SoC (Cyclone V 5CSEMA5F31C6)
- VGA monitor

## Tools
- Quartus Prime
- ModelSim/Questa
